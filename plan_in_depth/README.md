# M03 — plan and TODO

This branch carries two files and nothing else:

- `M03_GitHub_Analyzer.md` — the specification.
- `M03_GitHub_Analyzer_TODO.md` — the running state: what is done, what is next, and
  what is deliberately deferred.

**Why a separate branch.** The module's own history should be about its code.
Keeping the plan here means `main` stays readable as a record of what was
built, and this branch stays readable as a record of what was decided.

Read the TODO first when starting a session. Update it as things land — a stale
list is worse than no list, because the next session trusts it.
